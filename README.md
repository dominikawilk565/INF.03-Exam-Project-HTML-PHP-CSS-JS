It demonstrates my skills in **HTML, CSS, JavaScript, PHP, and MySQL**.

## 🤖 Technologies
- HTML5
- CSS3
- JavaScript
- PHP 7+
- MySQL

## 💻 How to open on your PC?
1. Copy the project files.  
2. Install and open **XAMPP**.  
3. Place the project folder in `C:\xampp\htdocs`.  
4. Start **Apache** (and **MySQL** if needed).  
5. Open your browser and go to `http://localhost/your-project-folder/`.
